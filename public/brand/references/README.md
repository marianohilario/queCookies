# Archivos originales para el rediseño

Colocar aquí las referencias del negocio para trabajar con el archivo real, no solo con su vista en el chat:

- `logo-original.png` o `logo-original.svg`: logo «que cookiss» sin modificar.
- `patron-marca.png` o archivos vectoriales: cookies, manos y corazones.
- `referencia-web.png`: mockup completo a la máxima resolución disponible.
- `hero-original.png` o `.jpg`, si existe la fotografía del plato por separado.

No sustituir los originales por versiones editadas. El logo corregido y los recursos finales tendrán nombres y rutas separados.

Esta carpeta está bajo public: incluir únicamente recursos de marca destinados a ser públicos, no archivos con datos privados.
